# Glossari

Fem servir el vocabulari tècnic correcte, tant al portafoli com al pitch. No diguem «la cosa que fa llum»: diguem **díode electroluminescent o LED**.

| Terme | Què vol dir |
|---|---|
| **Litofania** | Placa de gruix variable que mostra una imatge quan la il·lumineu per darrere |
| **STL** | Format de fitxer per a models 3D que llegeixen els programes de laminació |
| **Laminador** (*slicer*) | Programa que converteix un model 3D en les instruccions de la impressora; fem servir Cura |
| **Alçada de capa** | Gruix de cada capa de plàstic. Com més petita, més detall i més temps d'impressió |
| **Ompliment** (*infill*) | Percentatge de l'interior de la peça que s'omple de material |
| **Suports** | Estructures temporals que sostenen les parts que queden en l'aire durant la impressió |
| **Vora** (*brim*) | Capa fina addicional a la base que ajuda la peça a enganxar-se al llit |
| **Deformació** (*warping*) | Quan les cantonades de la peça s'aixequen del llit durant la impressió |
| **PLA** | Plàstic que fem servir a la impressora 3D |
| **LED** | Díode electroluminescent: component que emet llum quan hi passa corrent |
| **Ànode / Càtode** | Les dues potes del LED: l'ànode (+) és la pota llarga i el càtode (−) la curta |
| **Resistència** | Component que limita el corrent perquè el LED no es cremi |
| **Llei d'Ohm** | Relació entre tensió, corrent i resistència: V = R · I |
| **Passacables** | Forat per on surt el cable de la capsa |
| **Cicle de vida** | Totes les fases d'un producte: producció, ús i fi de vida |
