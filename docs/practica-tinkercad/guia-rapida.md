# Guia ràpida de Tinkercad

Aquesta pàgina és per consultar quan no recordeu com es fa alguna cosa. Totes les mesures són en **mil·límetres (mm)**.

## Què vull fer?

| Vull... | Com es fa |
|---|---|
| **Afegir una forma** | Arrossegueu-la des del panell de la dreta (formes bàsiques) fins al pla de treball |
| **Posar-li una mida exacta** | Cliqueu la forma i, després, un dels quadradets blancs de les cantonades. Escriviu la mida als quadres que apareixen |
| **Canviar el color** | Panell de propietats de la forma: trieu el color a **Solid** |
| **Fer un forat** | Panell de propietats: canvieu **Solid** per **Hole** (forat). En agrupar-la amb una peça sòlida, hi fa un buit |
| **Fer un cilindre llis** | Al panell de propietats, poseu **Sides** (costats) al màxim |
| **Moure una peça amunt o avall** | Cliqueu la fletxa negra que hi ha a sobre de la forma i escriviu l'alçada en mm |
| **Alinear peces** | Seleccioneu-les totes i premeu **L** (eina Align). Cliqueu els punts d'alineació de cada eix |
| **Girar una peça 90°** | Cliqueu la peça i arrossegueu una de les fletxes corbes, o escriviu els graus al quadre que apareix |
| **Alinear pel centre, pel davant o pel darrere** | Amb l'eina Align (**L**) trieu, a cada eix, el punt d'alineació: el del mig per centrar, o el d'un costat per alinear-ho per aquell cantó |
| **Agrupar** | Seleccioneu les peces i premeu **Ctrl + G** |
| **Desagrupar** | **Ctrl + Maj + G** |
| **Deixar una peça sobre el pla de treball** | Premeu **D** |
| **Duplicar** | **Ctrl + D** |
| **Mesurar** | Premeu **R** per posar una regla |

## Tres trucs que us estalviaran errors

!!! tip "El diàmetre d'un cilindre o d'un con"
    Quan l'enunciat us parla del **diàmetre**, escriviu aquest valor a les dues mides de la base (longitud i amplada).

!!! tip "Posar una peça damunt d'una altra"
    Primer, pugeu-la amb la fletxa negra escrivint l'**alçada de la peça de sota**. Després, centreu-la amb l'eina Align (**L**) als eixos horitzontals.

!!! tip "Comproveu abans d'agrupar"
    Un cop agrupades, les peces es comporten com una sola. Mireu l'objecte des de diferents vistes abans de premer Ctrl + G.

## Prisma, cub i forma

A Tinkercad la forma s'anomena **Box** i serveix tant per a cubs com per a prismes. Els exercicis diuen «cub» o «prisma» segons si totes les cares són iguals.
